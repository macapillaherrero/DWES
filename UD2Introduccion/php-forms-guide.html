Envío y Recepción de Información (UD 2-3)

PHP se usa para procesar datos enviados desde el cliente (navegador web). La forma más común de hacerlo es a través de formularios HTML y variables superglobales.

Variables Superglobales

Algunas variables predefinidas en PHP son "superglobales", lo que significa que están disponibles en todos los ámbitos a lo largo del script. No es necesario emplear `global` para acceder a ellas dentro de las funciones.

  • $GLOBALS
  • $_SERVER
  • $_ENV
  • $_GET
  • $_POST
  • $_REQUEST
  • $_COOKIE
  • $_SESSION
  • $_FILES

`$_GET`

El método GET envía datos a través de la URL. Son visibles para el usuario y tienen un límite de tamaño.

// Ejemplo de URL con datos GET https://www.google.es/search?q=metodo+get+php
  • Los datos se añaden a la URL después de un `?` y se separan por `&`.
  • El tamaño máximo varía según el navegador (ej. Firefox: ~65,536 caracteres).
  • Se usa para solicitudes que no modifican datos en el servidor (ej. búsquedas, filtros).

`$_POST`

El método POST envía datos en el cuerpo de la solicitud HTTP. No son visibles en la URL y no tienen un límite práctico de tamaño.

// Ejemplo de cómo se vería el array POST Array ( [nombre] => Marian [dir] => [tel] => [bt_enviar] => Enviar )
  • Ideal para enviar información sensible (contraseñas, datos personales).
  • Se usa para solicitudes que modifican datos en el servidor (ej. registro, envío de formulario).

`$_REQUEST`

Es un array que contiene la unión de los datos de `$_GET`, `$_POST` y `$_COOKIE`. Es una forma conveniente de acceder a los datos sin importar el método, pero se recomienda usar `$_GET` o `$_POST` directamente por motivos de seguridad y claridad.

// Acceder a un valor sin importar el método de envío $nombre = $_REQUEST["nombre"];

Interacción con el usuario (Formularios)

Los formularios HTML son la principal forma de capturar la información del usuario en una página web. El atributo `method` en la etiqueta `

` especifica si se usará GET o POST.

Ejemplo de Formulario HTML

<form action="formulario_envia_recibe.php" method="post"> Nombre : * <input type="text" name="nombre" > Dirección : * <input type="text" name="dir" value="" > Teléfono : * <input type="text" name="tel"><br> Condiciones : * <input type="checkbox" name="condiciones" value="on"> <input type="submit" name="bt_enviar"> </form>

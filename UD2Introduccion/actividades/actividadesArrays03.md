# Ejercicios de Arrays en PHP

1. Crea un array con los meses del año ordenados: “enero, febrero…” Dale la vuelta para que queden de este modo: “diciembre, noviembre…”.  
   Crea un bucle que, sin salirse del array, muestre los meses uno debajo del otro, empezando desde enero.

2. Rellena un array con 10 números aleatorios y ordénalos de mayor a menor.

3. Crea un array con los meses del año, saca enero y febrero del array y añádelos al final del mismo.

4. Rellena un array con números pares del 0 al 20. Puedes hacerlo con un bucle y usando el %2 (módulo de 2).

5. Crea una función que calcule el factorial de un número y llámala para cada elemento del array.

6. Crea un array de edades con las siguientes edades: `[14, 18, 19, 25, 84, 45, 87, 56, 28, 9, 35, 64]`  
   Comprueba si **todas** las edades están entre 18 y 65.

7. Sobre el mismo array de edades, averigua si **hay alguna mayor que 67**.

8. Sobre el mismo array de edades, averigua si **hay alguna menor que 15**.

9. Sobre el mismo array, obtén el **elemento menor**, muestra por pantalla cuál es y en qué posición del array está.

10. Con un bucle, rellena un array de dos dimensiones (matriz) de tamaño 6x5 y rellénalo con números aleatorios.  
    (_Te puede servir la función `rand`_)  
    Muestra la matriz que has rellenado en una **tabla**.

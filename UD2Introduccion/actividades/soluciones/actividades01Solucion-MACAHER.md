## Solución Actividad 2: Jugando con Variables

```php
<?php

```

## Solución Actividad 3: Calculadora Sencilla

```php

<?php
$num1 = 15;
$num2 = 5;

$suma = $num1 + $num2;
$resta = $num1 - $num2;
$multiplicacion = $num1 * $num2;

echo "La suma es: " . $suma . "<br>";
echo "La resta es: " . $resta . "<br>";
echo "La multiplicación es: " . $multiplicacion;
?>
```

## Solución Actividad 4: Uso de Comentarios

```php
<?php
/*
 Este script realiza operaciones aritméticas básicas (suma, resta y multiplicación)
 con dos números predefinidos y muestra los resultados.
*/

// Declaración de los dos números a operar
$num1 = 15;
$num2 = 5;

// Se realiza la operación de suma
$suma = $num1 + $num2;

// Se realiza la operación de resta
$resta = $num1 - $num2;

// Se realiza la operación de multiplicación
$multiplicacion = $num1 * $num2;

echo "La suma es: " . $suma . "<br>";
echo "La resta es: " . $resta . "<br>";
echo "La multiplicación es: " . $multiplicacion;
?>
```

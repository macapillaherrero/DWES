Arrays en PHP (UD 2-2)

Un array en PHP es un mapa ordenado que asocia valores a claves. Son una herramienta fundamental para almacenar y manipular colecciones de datos.

Arrays Numéricos

Un array numérico utiliza enteros como claves. Las claves se asignan automáticamente comenzando desde 0.

Creación de Arrays Numéricos

// Opción 1 $vector = array('Uno', 'Dos', 'Tres'); // Opción 2 $vector[0] = 'Uno'; $vector[1] = 'Dos'; $vector[2] = 'Tres'; // Opción 3 (forma más moderna) $vector[] = 'Uno'; $vector[] = 'Dos'; $vector[] = 'Tres';

Acceso a un elemento

echo $vector[1]; // Muestra "Dos"

Arrays Asociativos

Utilizan cadenas de texto como claves. Son ideales para representar datos con etiquetas descriptivas.

Creación de Arrays Asociativos

// Opción 1 $notas = array('Manuel García' => 8.5, 'Ana López' => 7, 'Juan Solís' => 9); // Opción 2 $notas['Manuel García'] = 8.5; $notas['Ana López'] = 7; $notas['Juan Solís'] = 9;

Acceso a un elemento

echo $notas['Manuel García']; // Muestra 8.5

Arrays Multidimensionales

Arrays que contienen otros arrays. Puedes combinarlos con claves numéricas y asociativas.

Ejemplos de creación

// Numérico $tabla[0][0] = 34.1; $tabla[0][1] = 141; // Asociativo $tabla2 = array( array('nombre' => 'Juan', 'dni' => '1111A'), array('nombre' => 'Ana', 'dni' => '2222B') ); // Mixto $tabla2[0]['nombre'] = 'Juan García'; $tabla2[0]['dni'] = '11111111A'; $tabla2[0]['idiomas'][0] = 'inglés'; $tabla2[0]['idiomas'][1] = 'valenciano';

Recorrido de Arrays

El bucle `foreach` es la forma más común y legible de iterar sobre arrays. También se pueden usar `while` o `for`.

Con `foreach`

// Solo valores foreach ($notas as $nota) { echo $nota; } // Claves y valores foreach ($notas as $alumno => $nota) { echo "El alumno $alumno tiene un $nota"; }

Con otros bucles

// Con `while` while(list($alumno, $nota) = each($notas)) { echo "El alumno $alumno tiene un $nota"; } // Con `for` para arrays numéricos for ($i = 0; $i < count($tabla); $i++) { for ($j = 0; $j < count($tabla[$i]); $j++) { echo $tabla[$i][$j]; } }

Funciones para Arrays

PHP tiene una gran cantidad de funciones nativas para manipular arrays, como ordenar, contar y buscar.

// contar elementos count($array) // ordenar sort($array) // ordena por valor asort($array) // ordena por valor, manteniendo la clave ksort($array) // ordena por clave

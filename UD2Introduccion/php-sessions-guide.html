Cookies y Sesiones (UD 2-4)

Las cookies y las sesiones son mecanismos para mantener el estado de la aplicación entre múltiples solicitudes del cliente. Es decir, permiten que una aplicación "recuerde" información sobre un usuario entre páginas.

Ambos mecanismos deben ser iniciados siempre antes de cualquier otro elemento en la página, incluso de un espacio en blanco.

Cookies

Las cookies son pequeños archivos de texto que se guardan en el navegador del cliente. Tienen una fecha de expiración y se envían en cada solicitud al servidor.

// Sintaxis de la función setcookie bool setcookie(string $name [, string $value [, int $expire [, string $path [, string $domain [, bool $secure [, bool $httponly]]]]]])

Ejemplo de Uso

<?php setcookie("nombre", "Pepito Conejo", time() + 60); // La cookie durará 1 minuto // Para leer la cookie, se accede al array superglobal $_COOKIE echo $_COOKIE["nombre"]; // Muestra "Pepito Conejo" ?>

Sesiones

A diferencia de las cookies, las sesiones almacenan la información en el servidor. El cliente solo guarda un identificador único (ID de sesión) para que el servidor pueda recuperar los datos.

// 1. Iniciar la sesión session_start(); // 2. Guardar un dato en la sesión $_SESSION["loginUsuario"] = $_REQUEST["login"]; // 3. Eliminar un dato de la sesión unset($_SESSION["loginUsuario"]); // 4. Eliminar completamente la sesión session_destroy(); // 5. Comprobar el estado de la sesión session_status();

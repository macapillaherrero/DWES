# Actividades de Programación Estructurada en PHP



### Actividad 1: Manipulación básica de cadenas

**Objetivo:** Familiarizarse con las funciones de cadenas `strlen` y `strtoupper`.
**Enunciado:** Crea un script que declare una variable con tu nombre completo. A continuación, debe mostrar por pantalla dos mensajes:

1. La longitud total de tu nombre (número de caracteres).
2. Tu nombre completo convertido a mayúsculas.

### Actividad 2: Estructuras de control (Selección)

**Objetivo:** Utilizar la estructura de control `if-else`.
**Enunciado:** Escribe un script que declare una variable numérica. Usando una estructura `if-else`, el programa debe determinar si el número es par o impar y mostrar un mensaje claro por pantalla, como "El número X es par" o "El número X es impar".

### Actividad 3: Estructuras de control (Iteración)

**Objetivo:** Implementar un bucle `for` para realizar una tarea repetitiva.
**Enunciado:** Crea un programa que muestre la tabla de multiplicar del número 7. Debe mostrar los resultados desde 7x1 hasta 7x10.

### Actividad 4: Funciones definidas por el usuario

**Objetivo:** Modularizar el código mediante la creación de una función simple con parámetros.
**Enunciado:** Define una función llamada `calcularCuadrado` que reciba un número como parámetro y devuelva su valor elevado al cuadrado. Llama a la función con un número de ejemplo (por ejemplo, 8) y muestra el resultado por pantalla.

### Actividad 5: Combinando bucles y funciones de cadena

**Objetivo:** Integrar el uso de bucles con la manipulación de cadenas.
**Enunciado:** Escribe un script que tome una cadena, por ejemplo, "Desarrollo Web", y la muestre invertida ("beW ollorraseD"). Para ello, puedes usar un bucle `for` que recorra la cadena desde el final hasta el principio.

### Actividad 6: Funciones con parámetros por defecto

**Objetivo:** Entender cómo funcionan los argumentos opcionales en las funciones.
**Enunciado:** Crea una función llamada `generarSaludo` que reciba dos parámetros: `$nombre` y `$saludo`. El parámetro `$saludo` debe tener el valor por defecto "¡Hola,". El script debe realizar dos llamadas a la función:

1. Una pasando solo el nombre.
2. Otra pasando el nombre y un saludo personalizado, como "Bienvenido".

### Actividad 7: Paso de parámetros por referencia

**Objetivo:** Comprender la diferencia entre el paso por valor y por referencia.
**Enunciado:** Define una función `incrementar` que reciba una variable numérica por referencia y aumente su valor en 10. Fuera de la función, inicializa una variable con el valor 5, pásala a la función y, después de la llamada, muestra su valor para comprobar que ha sido modificada.

### Actividad 8: Uso de variables estáticas en funciones

**Objetivo:** Practicar el uso de `static` para que una variable conserve su valor entre llamadas.
**Enunciado:** Crea una función `contarLlamadas` que utilice una variable estática para llevar la cuenta de cuántas veces ha sido invocada. Cada vez que se ejecute, debe mostrar el mensaje: "Esta función ha sido llamada X veces". Llama a la función 3 o 4 veces seguidas para verificar que el contador funciona correctamente.

### Actividad 9: Función con lógica compleja (condicionales y bucles)

**Objetivo:** Desarrollar una función que requiera una lógica de resolución más elaborada.
**Enunciado:** Escribe una función `esPrimo` que reciba un número y devuelva `true` si es un número primo y `false` si no lo es. Después, crea un script que utilice un bucle `for` para recorrer los números del 1 al 50 y muestre por pantalla cuáles de ellos son primos, utilizando la función que has creado.

### Actividad 10: Mini-calculadora estructurada

**Objetivo:** Integrar todos los conceptos aprendidos para crear una pequeña aplicación funcional.
**Enunciado:** Crea una "mini-calculadora" que funcione a través de funciones.

1. Define cuatro funciones: `sumar`, `restar`, `multiplicar` y `dividir`. Cada una debe aceptar dos números como parámetros y devolver el resultado.
2. La función `dividir` debe incluir una validación para evitar la división por cero. Si el segundo número es cero, debe devolver un mensaje de error en lugar de un resultado numérico.
3. Escribe un script principal que defina dos variables numéricas y llame a las cuatro funciones para mostrar los resultados de todas las operaciones.

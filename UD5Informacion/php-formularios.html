Variables Superglobales

En PHP, las variables superglobales están siempre disponibles. Para formularios, las esenciales son:

  • $_GET: Datos enviados por la URL.
  • $_POST: Datos enviados en el cuerpo de la petición.
  • $_REQUEST: Combina $_GET, $_POST y $_COOKIE.
  • $_SERVER: Información del servidor y entorno de ejecución.

Método GET

Envía datos visibles en la URL. Ideal para búsquedas, filtros o paginación.

Formulario GET

<form action="#" method="get">
  <label for="search_get">Buscar:</label>
  <input type="text" id="search_get" name="termino">
  <button type="submit">Enviar</button>
</form>

Procesamiento PHP


<?php
$termino = $_GET['termino'] ?? 'nada';
echo "Búsqueda: " . htmlspecialchars($termino);
?>

Método POST

Envía datos de forma no visible. Es el estándar para información sensible o acciones que modifican datos.

<form action="#" method="post">
  <label for="name_post">Nombre:</label>
  <input type="text" id="name_post" name="nombre">
  <button type="submit">Enviar</button>
</form>

Método REQUEST

Combina datos de $_GET, $_POST y $_COOKIE. Útil cuando no importa el método de envío.

<?php
$valor = $_REQUEST['clave'] ?? 'valor por defecto'; 
echo "Valor recibido: " . htmlspecialchars($valor);
?>

Variable $_SERVER

Proporciona información sobre el servidor y el entorno de ejecución. Útil para obtener detalles como la URL actual, método de solicitud, etc.

<?php
echo "Método de solicitud: " . $_SERVER['REQUEST_METHOD']."
";
echo "URL actual: " . $_SERVER['REQUEST_URI']."
";
echo "Host: " . $_SERVER['HTTP_HOST']."
";
echo "Protocolo: " . $_SERVER['SERVER_PROTOCOL']."
";
echo "Nombre del servidor: " . $_SERVER['SERVER_NAME']."
";
echo "Puerto del servidor: " . $_SERVER['SERVER_PORT']."
";
echo "Agente de usuario: " . $_SERVER['HTTP_USER_AGENT']."
";
echo "Dirección IP del cliente: " . $_SERVER['REMOTE_ADDR']."
";
echo "Dirección url de la página que nos enlazó: " . $_SERVER['HTTP_REFERER']."
";
echo "Dirección de esta página: " . $_SERVER['PHP_SELF']."
";
?>
Pordemos consultar otras opciones en la documentación oficial de PHP: $_SERVER - Manual de PHP

<?php
    //Recepción de un input de texto sencillo
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $nombre = trim($_POST['nombre'] ?? '');
    echo "Nombre recibido: " . htmlspecialchars($nombre);   

    //Recepción de un radiobutton
    $genero = $_POST['genero'] ?? 'no especificado';
    echo "Género seleccionado: " . htmlspecialchars($genero);   

    //Recepción de un checkbox
    $intereses = $_POST['intereses'] ?? [];
    echo "Intereses seleccionados: " . implode(", ", array_map('htmlspecialchars', $intereses));

    //Recepción de un option
    $pais = $_POST['pais'] ?? 'no especificado';
    echo "País seleccionado: " . htmlspecialchars($pais);

    //Recepción de un option multiple
    $paises = $_POST['pais2'] ?? []; 
    echo "Países seleccionados: " . implode(", ", array_map('htmlspecialchars', $paises));
    
    //Recepción de un textarea
    $comentarios = trim($_POST['comentarios'] ?? '');
    echo "Comentarios recibidos: " . htmlspecialchars($comentarios);

}

Explicación del Código:

1. Input de Texto:

  • Usamos el operador de fusión null (??) para proporcionar un valor por defecto si el campo no está presente.
  • Usamos trim() para eliminar espacios en blanco y htmlspecialchars() para prevenir el Cross-Site Scripting (XSS).

El Cross-Site Scripting (XSS) es un tipo de ataque informático que inyecta código malicioso, generalmente JavaScript, en sitios web de confianza. Este código se ejecuta en el navegador de la víctima, permitiendo al atacante robar información confidencial como cookies o tokens de sesión, tomar el control de la cuenta del usuario, redirigirlo a sitios maliciosos o alterar el contenido del sitio web. Los ataques ocurren porque el sitio web no valida o sanitiza adecuadamente la entrada del usuario antes de mostrarla.

2. Radiobutton: Verificamos si se ha seleccionado un valor y proporcionamos un valor por defecto si no es así.

3. Checkbox: Dado que un checkbox puede tener múltiples valores seleccionados, se envía como un array. Usamos array_map('htmlspecialchars', $intereses) para aplicar la función htmlspecialchars a cada elemento del array antes de unirlos con implode.

4. Option: Similar al radiobutton, verificamos si se ha seleccionado un valor y proporcionamos un valor por defecto si no es así.

5. Option Múltiple: Al igual que con los checkboxes, los valores seleccionados se envían como un array. Aplicamos htmlspecialchars a cada elemento del array antes de unirlos para prevenir XSS.

6. Textarea: Usamos trim() para eliminar espacios en blanco y htmlspecialchars() para prevenir XSS.

Validación Completa: Formulario Autoprocesado

Esta es la práctica profesional estándar: un único script PHP que muestra el formulario y procesa los datos. Si hay errores, recarga el formulario mostrando los fallos y manteniendo los datos que el usuario ya había introducido.

<?php
$errores = [];
$nombre = $email = '';

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $nombre = trim($_POST['nombre'] ?? '');
    $email = trim($_POST['email'] ?? '');

    if (empty($nombre)) $errores['nombre'] = 'El nombre es obligatorio.';
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) $errores['email'] = 'El email no es válido.';

    /*
    filter_var() es una función en PHP que se utiliza para filtrar y validar datos.
    Toma dos argumentos principales: la variable que deseas filtrar y el tipo de filtro que quieres aplicar.
    En este caso,    
    FILTER_VALIDATE_EMAIL es una constante predefinida en PHP que se utiliza con la función filter_var() 
    para validar si una cadena dada tiene el formato correcto de una dirección de correo electrónico.*/

    if (empty($errores)) {
        // Lógica de éxito: guardar en BBDD, etc.
        echo "<div>¡Registro completado con éxito!</div>";
        exit();
    }
}
?>

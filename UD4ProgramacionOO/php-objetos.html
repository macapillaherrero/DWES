Programación Orientada a Objetos (POO) en PHP

Las Clases y Objetos

<?php
class Caja {
  public $color = 'rojo';
  public $alto = 10;
  public $ancho = 10;
  public function mostrarCaja() {
    echo "Mi caja es de color: {$this->color}";
    echo " y mide {$this->alto} x {$this->ancho}";
  }
}
$miCaja = new Caja();
$miCaja->mostrarCaja();
?>

Constructores y Destructores

<?php
class Persona {
  public $nombre;
  public $apellido;
  public $edad;
  
  public function __construct($nombre, $apellido, $edad) {
    $this->nombre = $nombre;
    $this->apellido = $apellido;
    $this->edad = $edad;
  }
  
  public function saludar() {
    return "Hola, soy $this->nombre $this->apellido y tengo $this->edad años.";
  }
  
  public function __destruct() {
    echo "Objeto destruido";
  }
}
$persona = new Persona("Pepita", "Pérez", 26);
echo $persona->saludar();
unset($persona);
?>

Visibilidad (public, private, protected)

Define acceso a propiedades y métodos para proteger datos y comportamientos.

<?php
class MyClass {
  public $public = "público";
  protected $protected = "protegido";
  private $private = "privado";
  
  public function imprimir() {
    echo $this->public;
    echo $this->protected;
    echo $this->private;
  }
}
$obj = new MyClass();
echo $obj->public;    // OK
// echo $obj->protected; // Error
// echo $obj->private;   // Error
$obj->imprimir();
?>

Métodos Mágicos __get y __set

Permiten manejar propiedades inaccesibles directamente.

<?php
class Example {
  private $data = [];
  
  public function __get($name) {
    return $this->data[$name] ?? null;
  }
  
  public function __set($name, $value) {
    $this->data[$name] = $value;
  }
}
$obj = new Example();
$obj->foo = "bar";
echo $obj->foo; // bar
?>

Herencia

Permite que una clase herede propiedades y métodos de otra usando extends.

<?php
class Animal {
  private $peso;
  private $color;
  
  public function __construct($peso, $color) {
    $this->peso = $peso;
    $this->color = $color;
  }
  
  public function getColor() {
    return $this->color;
  }
}

class Gato extends Animal {
  private $raza;
  
  public function __construct($peso, $color, $raza) {
    parent::__construct($peso, $color);
    $this->raza = $raza;
  }
}

$gato = new Gato(5, "blanco", "persa");
echo $gato->getColor();
?>

Clases Abstractas

Clases que no se pueden instanciar directamente, pero que definen métodos que las clases hijas deben implementar.

<?php
abstract class ProductoLacteo {
  abstract public function conservarse();
  abstract public function consumirse();
}

class Leche extends ProductoLacteo {
  public function conservarse() {
    echo "Conservar en la nevera.";
  }
  public function consumirse() {
    echo "Beber el producto.";
  }
}
?>

Palabra Clave Final

Impide que las clases hijas sobrescriban un método o extiendan una clase final.

<?php
final class ImposibleHeredar {
  public function test() {
    echo "Llamada a ImposibleHeredar::test()";
  }

  final public function moreTesting() {
    echo "Llamada a ImposibleHeredar::moreTesting()";
  }
}

// Esto genera error:
// class IntentoHeredar extends ImposibleHeredar {}

class ParcialHeredar {
  public function test() {
    echo "Llamada a ParcialHeredar::test()";
  }

  final public function moreTesting() {
    echo "Llamada a ParcialHeredar::moreTesting()";
  }
}

class IntentoHeredar extends ParcialHeredar {
  // Error al intentar sobreescribir método final
  // public function moreTesting() {}
}
?>
